# 치이카와 연타 게임 — 웹페이지 뼈대 v0.2

## 현재 작동하는 기능
- 제작자 화면: 제목, 엔딩(도망/메시지), 메시지, 난이도, 막판 발악 모드
- 플레이어 화면: 연타 게이지, 시간 경과에 따른 감소, 4단계 반응 문구, 엔딩, 다시 하기
- 제작자 설정을 URL에 넣는 공유 링크 생성

## 실행
압축 해제 후 index.html을 브라우저에서 열면 됩니다. 다른 사람이 링크로 접속하려면 GitHub Pages 등에 배포해야 합니다.

## 향후 작업
assets/characters/ 에 직접 그린 PNG 4~7장을 넣고 script.js의 단계 변경 처리에서 표시 이미지를 연결합니다. 모션·효과·폰트는 이후 추가합니다.

## 주의
URL 인코딩은 암호화가 아니므로 메시지는 링크를 분석하면 확인할 수 있습니다. 비밀이나 개인정보는 넣지 마세요.
